08Flutter 実装者向け 引き継ぎ
A. 共通（theme/ に集約・全画面に効く）
・ColorScheme：fromSeed の結果を copyWith で上書き（上の 00 の値）。dynamicColor は使わない
・TextTheme：GoogleFonts.notoSansJp をベースに、数値・日付・メールのみ GoogleFonts.archivo。letterSpacing は display/headline に -0.03〜-0.05em
・全 elevation を 0：CardTheme / AppBarTheme(scrolledUnderElevation:0, elevation:0) / DialogTheme / NavigationBarTheme / BottomSheetTheme
・DividerTheme：color を transparent にし、ListView.separated の separator は SizedBox(height:20) に置換
・ListTileTheme：contentPadding 水平0・minVerticalPadding 0（画面側の24パディングに揃える）／trailing の chevron は削除
・Filled/Outlined/TextButton：radius 8、高さ 48、labelLarge 13/w600。disabled は onPrimary 30%
・InputDecorationTheme：filled:false、UnderlineInputBorder(1px)／focused 2px、floatingLabel は使わず外側に labelSmall を置く
・NavigationBar：labelBehavior:alwaysHide、indicatorColor transparent、選択＝塗りアイコン／非選択＝outlined、icon size 22（実機。モック15pxは縮尺）、height 64
・SnackBar は使わない：エラーは画面内インライン（太字＋下線＋「！」）
B. 画面ごとの変更点
ログイン：Google / Apple / 電話番号の3つの OutlinedButton を画面から外し、TextButton「他の方法でログイン」→ showModalBottomSheet 内の ListTile 3行に移動。ボタン数 5→1。エラーは入力欄直下にインライン。
アカウント登録 / パスワード再設定：送信後状態を「見出し（headlineSmall）＋説明（bodyMedium）＋ログインに戻る TextButton」に統一。中央寄せ→左寄せ。
電話番号ログイン：上部に STEP 1 — STEP 2 のテキストインジケータを追加（新規キー1件）。OTP 欄は letterSpacing 0.42em の Archivo。
アイテム一覧：AppBar タイトル据え置き＋body 冒頭に件数の displayLarge を追加（既存の itemCount から算出、新規キー「件」＝items.countUnit）。Divider と trailing chevron を削除、行間 20。RefreshIndicator は色を onSurface に。スケルトンは skeletonizer の色を surfaceContainer→#DEDEDA/#333331 に固定し 6件に。
アイテム詳細：body 冒頭にタイトル再掲（headlineSmall）＋メタ行（Updated / ID）。ローディングは CircularProgressIndicator → スケルトン（新規 SkeletonDetailView は作らず SkeletonListView のバリアント引数で対応可）。
設定：ListTile の leading アイコンを全廃。テーマ・言語・アカウント・バージョンを 2列グリッドの LabelValue に、規約・ポリシー・プロフィールはテキスト行に分離。DropdownButton は値のテキスト＋▼のみ（下線・枠なし）。退会は最下部、太字＋下線。
退会ダイアログ：主ボタン（FilledButton）をキャンセルに割り当て、「退会する」を TextButton（太字＋下線）に降格。ボタン配置は縦積み。
オンボーディング：96px アイコン → 「01/02/03」の displayLarge。中央に差し替え用の空き領域（AspectRatio で確保）。インジケータのドット → 幅 26/12 の下線バー。
プロフィール / 編集：中央 radius48 アバター → 左寄せ 64px（AppAvatar の size 引数で対応）。表示名を headlineSmall で隣に。項目は LabelValue。編集は下線入力＋保存中 30%＋上部 2px LinearProgressIndicator。
ホーム：中央のアプリ名テキストを廃止し、雛形として「主数値（displayLarge）＋LabelValue 2個＋直近3件＋差し替え領域のコメント付き Placeholder」を配置。データ源は既存の items プロバイダのみで、新規の集計ロジックは持たない（未対応件数＝items.length などの単純な派生値）。空状態は EmptyView を再利用。
メンテナンス / 強制アップデート：64px アイコン廃止、左寄せの大型見出し＋本文。強制アップデートに現在→最新バージョンのメタ行を追加（既存の取得値を表示するだけ）。
C. 新規コンポーネント（2件のみ）
LabelValue（lib/core/widgets/label_value.dart）／ 理由：ラベル＋値の2段ペアが設定・プロフィール・ホーム・詳細の4画面で計20箇所以上に出るため。仕様：LabelValue({required String label, required String value, Widget? trailing, bool mono = false}) — labelSmall（onSurfaceVariant）＋ 間隔2 ＋ titleMedium（onSurface）。mono:true で値を Archivo tabular に。値は maxLines 1 + ellipsis。
DisplayHeader（lib/core/widgets/display_header.dart）／ 理由：「小見出し＋日付＋大型数値」の画面冒頭パターンをホーム・アイテム一覧・設定で共通化するため。仕様：DisplayHeader({required String title, String? meta, String? display, String? displayUnit}) — display は displayLarge、unit は bodySmall をベースライン揃え。
上記以外は既存の EmptyView / ErrorView / SkeletonListView / AppAvatar / AppNetworkImage をそのまま使用（EmptyView は説明文とCTAの任意引数を追加するのみ、ErrorView は「！」表示と下線見出しに差し替え）。
